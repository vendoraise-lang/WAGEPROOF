## Architecture and measurements
Proposal Preflight retains its Node HTTP server, deterministic rule engine, responsive interface and HTML/CSV exports. Up to 30 explicit English requirements against a short plain-text draft; duration/unit comparisons, uptime, coverage and process questions with cited passages. Matching fallback and uncertainty are disclosed; no certification, paid AI calls, uploads or server document retention. Complete reports remain free in beta. The Worker permanently forces test mode and disables live payments.

The separate factory uses its existing SQLite Durable Object. Additive schema migration preserves prior data. Fixed-label daily aggregates now measure resource views → checklist-tagged product views → review events → downloads → nonbinding $9-interest clicks. Attribution follows same-tab API calls without retaining arbitrary referrers, IPs, identities or document text. Dashboard distinguishes attributed funnel, product-wide events and test funnel. These are events, not unique visitors, session conversion rates, customers or verified human traffic. Repeat and spoofed events remain possible. Historic untagged counts cannot retrospectively be cleaned.

Known bots/operator agents and empty user agents are excluded. Explicit test headers segregate automated probes and browser tests; fictional sample actions are tagged as tests. No revenue is inferred from clicks or test receipts. Aggregate retention is 90 days, dashboard window 30 days. Anonymous support/problem signals collect no contact information and cannot receive individual replies. Privacy disclosure matches the new counters.

Baseline at 2026-10-11 02:32 UTC: 7 untagged product pageviews, 0 non-test reviews/downloads, 0 measured resource views, 0 attributed referrals/reviews/interest clicks, 0 transactions and $0 verified revenue. The untagged pageviews are not verified genuine people or traction. Live tests proved attributed synthetic events persist without changing non-test counts.
